## Known limitations and residual risks

1. `report.schema.json` does not define how `summary.canary_hit_details` proves
   completeness relative to mode detections: it does not state whether
   `violation=false` entries are included or define grouping, ordering, or
   deduplication. The semantic validator therefore does not invent a completeness
   algorithm; Schema validation remains the enforceable boundary.
2. Direct dependencies are pinned, but the missing hashed transitive lock permits
   dependency resolution drift between fresh installs.
3. Domain/report/error validators are not the API, RAG pipeline, output detector,
   vector index, database, Ollama adapter, evaluation runner, or evidence store.
4. Synthetic tests cannot establish real-world safety, authorization, privacy,
   compliance, or model behavior.
5. The architecture-owned Stage 1 scope file remains an uncommitted input in this
   development worktree and must be preserved by the snapshot owner.
